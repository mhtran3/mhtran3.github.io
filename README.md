# Michael Tran's personal website

A static, accessible landing page for https://mhtran3.github.io/. Its collection-led layout introduces selected artwork, a game-design prototype, and teaching experience without reducing Michael to a single professional title.

## Preview

Serve this directory with a static HTTP server, for example `python -m http.server 8765`, and open http://localhost:8765.

No build step, third-party JavaScript, analytics, external fonts, or runtime dependencies are required. `index.html` contains all content and contact links. `home.css` controls the responsive layout; `home.js` progressively enhances project anchors into keyboard-accessible native dialogs. With JavaScript disabled, the full project notes remain available below the landing page.

## Assets and scope

The two WebP previews are optimized copies of existing public artwork in `(public)/MyArt/`. Original files are preserved. The decision diagram is an explanatory website illustration, not a game screenshot. Private planning notes, unreviewed Drive photographs, student materials, and sensitive autobiographical content are excluded from this landing page.

This first version provides a foundation for future project pages and everyday-life material. Links are limited to implemented sections and real contact destinations.
