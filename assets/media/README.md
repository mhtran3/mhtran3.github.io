# Selected media

All excerpts are silent H.264 at 960x540, with faststart and native controls. They are compressed copies of the original recordings; no footage is generated or composited into the game.

- **bloom-clearing.mp4**: Michael Tran's Bloom final film, 1:48–1:54. Visual artwork, animation, and compositing by Michael. Soundtrack omitted.
- **hotpot-process.mp4**: 0:02–0:20 of Michael's IMG_9985 timelapse. Four stills show the source at 0:10, 0:17.5, 0:40, and 0:55. Layer visibility changes are part of the original process recording. Festival context supplied by Michael: ZZZ 2025 Art Fest.
- **dungeon-heatmap.mp4**: 1:44–1:57 of the October 14, 2026 Godot viewport capture, Enchanted Grove. Existing automatic combat, with position scores and movement target visible.
- **dungeon-flow.mp4**: 0:58–1:12 of the same capture. Existing exploration flow field is displayed during combat; it is not the whole combat steering policy.

Game recordings used isolated save data and the existing Godot Movie Maker. No game code or outcomes were altered for the recording. Sprites and environment art are third-party assets; the case study describes system design, AI-assisted development, and testing. These excerpts are demonstrations, not benchmarks or proof of globally optimal behavior.
