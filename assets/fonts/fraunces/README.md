# Fraunces

By Phaedra Charles and Flavia Zimbardi (Undercase Type).
Design and source: https://fraunces.undercase.xyz/
Repository: https://github.com/undercasetype/Fraunces
SIL Open Font License 1.1 included in OFL.txt.

Unmodified Google Fonts WOFF2 subsets, downloaded October 18, 2026:
https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght,SOFT,WONK@9..144,500,50,0&display=swap

Normal style; weight 500; optical size 9–144. SOFT 50 and WONK 0 are fixed
by the upstream export. CSS leaves optical sizing automatic.

Latin: 34,292 bytes; extended Latin: 31,420; Vietnamese: 11,100.
Total: 76,812 bytes. The original font data is unmodified; local filenames
describe its family, weight, and character coverage.

Used for a few reflective passages: the opening statement and education quote on the homepage, and the openings of two stories.
Unicode ranges match the upstream CSS. No preload or runtime Google Fonts
request; font-display: swap keeps fallback text readable while loading.
