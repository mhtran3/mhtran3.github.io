# Bricolage Grotesque

By Mathieu Triay and the Bricolage Grotesque project contributors.
Design and story: https://ateliertriay.github.io/bricolage/
Source: https://github.com/ateliertriay/bricolage
License: SIL Open Font License 1.1, included in OFL.txt (no Reserved Font Name).

Made from the variable font in the Google Fonts family download (Version 1.001,
BricolageGrotesque-VariableFont_opsz,wdth,wght.ttf), October 21, 2026:
- width fixed at normal (100);
- weight limited to 400–600 (regular to semibold), which covers paragraphs (400),
  headings (500) and labels (600);
- optical size kept variable, 12–96, so the browser picks the right shapes for each size;
- split into Latin, extended Latin and Vietnamese subsets with the same unicode ranges
  as gallery.css, keeping all OpenType layout features (kerning, ligatures, Vietnamese
  mark positioning), and compressed to WOFF2. Outlines are unchanged.

Latin: 80,080 bytes; extended Latin: 27,892; Vietnamese: 11,820. Total: 119,792 bytes.
Subsets load on demand; no Google Fonts request is made by the website.
The stylesheet uses font-display: swap.

These replace the earlier medium-only (500) Google Fonts subsets; headings render the same.
