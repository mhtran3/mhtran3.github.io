Unmodified Google Fonts WOFF2 subsets, downloaded October 18, 2026:
https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500&display=swap

Normal style, medium (500) weight, normal width, optical size 12–96.
The character ranges in gallery.css match the upstream stylesheet.
Latin: 40,220 bytes; Latin extended: 17,844 bytes; Vietnamese: 8,304 bytes.
Total: 66,368 bytes. Subsets load on demand; no Google Fonts request is
made by the website. The stylesheet uses font-display: swap.

These font files retain their original names internally and have not been
modified. Public filenames describe the family, weight, and character subset.
